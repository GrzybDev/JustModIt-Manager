# Getting help

- **Problems or ideas for Menadżer Spolszczeń**: [its issues](https://github.com/GrzybDev/MenadzerSpolszczen/issues/new/choose),
  in Polish or English.
- **Problems in the code of either app**: [this repository's issues](https://github.com/GrzybDev/JustModIt-Manager/issues/new/choose).
- **A broken translation, your account or the site**: the [Baza Spolszczeń contact form](https://bazaspolszczen.pl/contact).
- **Security problems**: see [SECURITY.md](SECURITY.md). Please don't report them publicly.

Please search the existing issues first. In the app, Settings > "About" opens a report with your versions filled in.
