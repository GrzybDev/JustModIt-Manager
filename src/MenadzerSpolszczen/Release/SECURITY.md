# Security policy

Menadżer Spolszczeń is built from [JustModIt Manager](https://github.com/GrzybDev/JustModIt-Manager), and its security
policy applies here: only the latest release receives fixes, and vulnerabilities are reported privately, never in a
public issue, through [JustModIt Manager's security advisories](https://github.com/GrzybDev/JustModIt-Manager/security/advisories/new).

*Po polsku:* luki w zabezpieczeniach zgłaszaj prywatnie, przez
[zgłoszenie podatności w repozytorium JustModIt Manager](https://github.com/GrzybDev/JustModIt-Manager/security/advisories/new),
nigdy w publicznym zgłoszeniu. Poprawki trafiają tylko do najnowszego wydania.
